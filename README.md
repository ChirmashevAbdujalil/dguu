# Sertifikat sahifasi

Havolalar:
- `https://<domen>/`
- `https://<domen>/Softs/Certificate=True`

Barcha fayllar asosiy papkada joylashgan:
- `index.html`, `style.css`, `script.js` — sahifa
- `certificate.webp` — sertifikat rasmi (almashtirish uchun shu nom bilan yangi rasm qo'ying)
- `vercel.json` (Vercel) va `_redirects` (Netlify) — `/Softs/Certificate=True` havolasini `index.html` ga yo'naltiradi

Sahifa rasmni to'liq ekranda ko'rsatadi, o'ng yuqori burchakdagi
"Yuklab olish" tugmasi rasmni yuklab beradi.
